مجتمع اندیشه — نسخه متصل به Supabase

1) فایل‌های این پوشه را مستقیم در GitHub Pages آپلود کن.
2) داخل Supabase، فایل SUPABASE_SETUP.sql را در SQL Editor اجرا کن.
3) بعد سایت را باز کن.
4) ورود مدیر: admin / eskandari1234
5) ورود ساکن: شماره واحد + رمز شخصی موجود در جدول units.
6) مدیر می‌تواند واحدها، پرداخت‌ها و شارژها را تغییر دهد و همگام‌سازی کند.

کلید داخل supabase-config.js کلید Publishable است و Secret/service_role نیست.
این نسخه برای سادگی Policy عمومی دارد؛ برای نسخه عمومی/حساس بهتر است بعداً RLS اختصاصی ساکنین و Auth پیاده شود.
