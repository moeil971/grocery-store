مجتمع اندیشه - نسخه اصلاح شده برای GitHub

مشکل‌های اصلی این نسخه اصلاح شده‌اند:
1) شماره واحد از شناسه داخلی دیتابیس جدا شده است؛ بنابراین جابه‌جایی شماره واحد باعث جابه‌جایی/خرابی اطلاعات، پرداخت و شارژ نمی‌شود.
2) اگر شماره مقصد قبلاً وجود داشته باشد، شماره دو واحد با هم جابه‌جا می‌شود و اطلاعات هر واحد حفظ می‌شود.
3) ذخیره اطلاعات واحد تا موفقیت Supabase منتظر می‌ماند؛ پیام «ذخیره شد» فقط بعد از پاسخ موفق دیتابیس نمایش داده می‌شود.
4) بارگذاری اولیه از Supabase انجام می‌شود و localStorage قدیمی دیگر نمی‌تواند تغییرات ابری را بی‌دلیل برگرداند.
5) پرداخت جدید مستقیم در Supabase ثبت می‌شود و حذف پرداخت هم مستقیم روی همان رکورد انجام می‌شود.
6) ساختار تکراری و اسکریپت‌های تکراری فایل قبلی حذف شده‌اند.

مهم: قبل از استفاده از نسخه جدید، فایل SUPABASE_SETUP.sql را یک بار در Supabase > SQL Editor اجرا کنید.
بعد از اجرای SQL، کل فایل‌های این ZIP را در repository گیت‌هاب جایگزین کنید.
